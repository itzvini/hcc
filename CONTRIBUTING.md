# Contributing to the Highrise Creature Club site

Thanks for wanting to help improve this site! Here's everything you need to get started.

## Who can contribute

Anyone in the Highrise Creature Club community. You don't need to hold an NFT to submit improvements to the site — just a GitHub account and good intent.

## Ways to contribute

- **Report a bug** — something broken, misaligned, or showing wrong info
- **Suggest a feature** — a new section, improvement to an existing one, or UX idea
- **Submit a fix** — open a pull request with your change

## Running locally

```bash
node server.js
```

Then open `http://localhost:3000`. No install step needed — there are no dependencies.

## Making a change

1. Fork the repo
2. Create a branch named after what you're doing: `fix/mobile-layout`, `feat/faq-entry`, etc.
3. Make your change and test it locally
4. Open a pull request against `main`

Keep each PR focused on one thing. A single fix or a single feature per PR makes review faster and history cleaner.

## What gets merged

- Bug fixes that are accurate and tested
- Content additions that are factually correct about HCC
- Visual/UX improvements that match the existing style
- Accessibility improvements

Changes that alter the HCC Council rules, election process, or Pocket Worlds commitments require sign-off from the team — don't worry, just open the PR and we'll discuss it there.

## Code style

- No build step, no framework — plain HTML, CSS, and vanilla JS
- Keep CSS in the `<style>` block in `index.html`, co-located with the markup
- Prefer readable code over clever code

## Opening issues

Use the issue templates. Fill them out as completely as you can — it makes triage much faster.

## Questions?

Open a discussion or drop a note in the HCC Discord.
